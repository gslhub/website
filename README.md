# GSLHub Website

Official website and research platform for **GSLHub — Generative Search Lab Hub**.

## Mission

GSLHub develops applied research in generative search, artificial intelligence, digital transformation, automation, SEO/GEO, open software and reproducible datasets.

## Initial stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Payload CMS
- PostgreSQL

## Status

Sprint 0 — Foundation.

## Local development

```bash
npm install
npm run dev
```

Create a local environment file from `.env.example` before connecting the CMS and database.

## Repository structure

```text
app/            Next.js App Router
components/     Shared UI components
content/        Static research content and seed data
lib/            Shared utilities
public/         Public assets
docs/           Technical and research documentation
.github/        CI and contribution workflows
```
