# Sprint 1 — Foundation & Design System

## Objective
Create the reusable foundation for GSLHub: navigation, responsive layout, design tokens, research cards, bilingual-ready content structure and baseline SEO/GEO files.

## Deliverables
- Responsive global navigation and footer
- Home page rebuilt from reusable components
- Design tokens and reusable UI primitives
- Research area cards and platform pillars
- `robots.txt`, `sitemap.xml` and `llms.txt`
- Structured metadata ready for academic entities
- Continuous integration on every push and pull request

## Definition of done
- `npm run lint`, `npm run typecheck` and `npm run build` pass
- Desktop and mobile layouts are usable
- All principal routes are represented in navigation
- Public metadata identifies GSLHub consistently
- Hostinger deploys automatically from `main`
